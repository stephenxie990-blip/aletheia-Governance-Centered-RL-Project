# Actor侧干净目标替换实现与验证 - 2026-03-16

## 本轮目标

把上一轮 `ACSC-v1` 从“在污染目标上做 corridor-aware 阻尼”，升级为“在 high-value corridor + negative advantage + absolute inflation 条件下，直接把 actor target 连续拉向 replay-grounded clean target”的单一主合同。

## 实现摘要

1. 在 imagined seed 采样阶段改为优先使用 `sample_sequences_with_remaining`，从而拿到 `episode_ids / step_indices`。
2. 新增 seed 对齐的 replay clean target 计算：
   - 从 seed 最后一步之后的真实 episode 后缀中提取 horizon 对齐的真实 reward/done。
   - 计算 inclusive discounted return，作为 actor-side clean target。
3. 在 `_build_imagined_batch()` 中新增：
   - `corridor_semantic_clean_target_blend_max`
   - `corridor_semantic_inflation_threshold`
   - `corridor_semantic_inflation_tau`
   - clean target 可用率、inflation gate、common-gap、blend 强度等指标。
4. actor 目标改为：
   - `target_actor_raw = returns`
   - `target_actor = lerp(target_actor_raw, clean_target, clean_target_blend_alpha)`
   - 其中 `clean_target_blend_alpha = clean_target_blend_max × corridor_mask × neg_adv_gate × inflation_gate × valid_mask`
5. 保留现有 ACSC-v1 的 corridor semantic blend，不再新增并联第六机制。
6. 在 CartPole pure-imag 训练入口中通过 `setdefault` 接入推荐默认值：
   - 不覆盖手工 overrides
   - 但标准 run 会默认带上本轮新合同
