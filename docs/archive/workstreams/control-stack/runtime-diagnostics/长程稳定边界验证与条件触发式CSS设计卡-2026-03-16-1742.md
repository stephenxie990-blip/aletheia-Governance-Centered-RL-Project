## 六、条件触发式 CSS-v1.1 设计

### 行为软门

用连续 `behavior_certainty` 代替硬阈值二值门：

```text
occ_score = clip((real_corridor_occupancy_fraction - 0.95) / 0.05, 0, 1)
persist_score = clip((real_corridor_persistence_rate - 0.95) / 0.05, 0, 1)
registry_score = clip((0.03 - real_policy_kl_to_certified_registry_mean) / 0.03, 0, 1)

behavior_certainty = occ_score * persist_score * registry_score
```

### solved 时长软门

```text
solved_streak_score = clip((solved_eval_streak - 2) / 2, 0, 1)
```

### 语义压力

```text
mc_pressure = clip((real_mc_value_gap_abs_mean - 60) / 30, 0, 1)
teacher_pressure = clip((teacher_value_abs_to_short_return_mean - 80) / 30, 0, 1)
imag_pressure = clip((imag_value_abs_to_short_return_mean - 85) / 30, 0, 1)

semantic_pressure = max(mc_pressure, teacher_pressure, imag_pressure)
```

### 最终清洗强度

```text
sanitation_pressure = behavior_certainty * solved_streak_score * semantic_pressure
```

### 作用方式

```text
effective_value_real_anchor =
    base_value_real_anchor * (1 + sanitation_boost * sanitation_pressure)

effective_post_solved_critic_anchor =
    base_post_solved_critic_anchor * (1 + anchor_boost * sanitation_pressure)
```

### 初始推荐值

- `sanitation_boost = 0.5`
- `anchor_boost = 0.5`
