# `v172` 真实训练运行审查与下一刀建议

## 1. 本轮结论

`AIA-ACSC-v3` 的第一阶段实现是准确的，但不充分。

它修对了一个真实结构缺口：

- `neg_adv` 不再是 clean target takeover 的硬开关
- 在 high-inflation slice 中，`floor + bonus` 确实把 clean target 接到了 actor 主链上

但它没有完成最终目标：

- clean target 的接管强度仍不足以压住 actor 主目标
- late-stage 仍发生大幅语义膨胀与 current-checkpoint 崩落

因此，本轮结论不是“方向错了”，而是：

> `takeover law` 从“接不上”修成了“能接上”，但还没有修到“能夺回主导权”。

## 4. 为什么 `v172` 会比 `v171` 更“结构正确”，却仍输给 `v170`

这是本轮最重要的诊断点。

### 4.1 `v172` 比 `v171` 更对

因为它修掉了 `v171` 最明确的结构缺口：

- `v171` 中 `neg_adv` 实际上是 clean target 的生死开关
- `v172` 中 clean target 至少获得了 inflation-driven 的基础接管

所以从结构合同上说，`v172` 是正确推进。

### 4.2 `v172` 为什么仍输给 `v170`

因为当前剩余主矛盾已经不是“能不能接上”，而是：

> clean target 的数值接管份额，仍远远小于污染 target/base 的膨胀幅度。

最关键的数据在 `2500`：

#### `v170 @2500`

- `target_mean = 26.91`
- `base_mean = 45.34`
- `clean_target_mean = 1.82`
- `blend = 0.0169`
- `weighted_actor_target_mean = 0.3599`

#### `v172 @2500`

- `target_mean = 71.39`
- `base_mean = 112.46`
- `clean_target_mean = 1.57`
- `blend = 0.0712`
- `weighted_actor_target_mean = 0.6474`

这说明：

1. `v172` 的 clean target 接管比例更高
2. 但同时污染 target/base 的原始量级膨胀得更厉害
3. 结果是：
   - 即使 alpha 更高
   - 最终 actor 实际优化的主目标仍更“热”

这就是为什么 `v172` 的设计更合理，但最终 hold 反而不如 `v170`。

## 5. 当前最收敛的病理判断

### 5.1 已经排除的旧病灶

当前不应再把主问题归因到：

- controller rescue 不够
- critic-only 校准不够
- detector 没拉响
- clean target 完全不可达

这些都已经不是最窄病灶。

### 5.2 当前真正的剩余病灶

当前最准确的表述应更新为：

> 在 severe inflation slice 中，clean target 已经进入 actor 主链，但其接管幅度仍然是“背景阻尼”，不是“主合同替代”。

更白话一点说：

- 以前的问题是：
  - clean target 进不来
- 现在的问题是：
  - clean target 进来了，但说话声音不够大

### 5.3 为什么会这样

根因不再是单一的 `neg_adv gate`。

当前剩余原因更像三者叠加：

1. severe inflation 时，污染 `target/base` 的原始数值继续急剧膨胀
2. clean target 虽然接管，但平均接管比例仍只有 `0.02~0.07`
3. 于是 actor 主推进器仍以污染目标为主，只是被 clean target 轻微阻尼

所以晚期现象就变成：

- `blend` 升高了
- 但 `weighted_actor_target_mean` 还是高
- 最终语义仍继续爆

## 6. 对 `AIA-ACSC-v3` 的结论

### 6.1 修了什么

修掉了一个真实而重要的结构 bug：

- clean target 不再完全受 `neg_adv` 符号绑架
- inflation 终于能直接推动 takeover

### 6.2 没修什么

没有修到：

- severe inflation 下 clean target 的最终主导权

### 6.3 是否修对了

修对了，但只修到一半。

更准确地说：

- `v3-A` 是必要修复
- 但不是终局修复

## 7. 下一刀建议

下一刀不应回到：

- controller rescue
- critic-only mainline
- 继续只补 detector / support

当前更优雅的下一步应该是：

> 继续留在 actor-side，但把 clean target 从“弱 blended correction”提升为“severe inflation slice 中的主导性替代合同”。

### 7.1 下一刀的设计原则

1. 不再盲扫 `floor_max`
   - 因为现在的问题不只是 alpha 小
   - 还包括 raw polluted target/base 膨胀太快
2. 必须直接对账：
   - `target_mean`
   - `base_mean`
   - `clean_target_mean`
   - `weighted_actor_target_mean`
3. severe inflation slice 中，需要更强的 clean-target 主导权
   - 而不是继续把它当成背景阻尼项

### 7.2 当前最合理的方向

优先考虑：

- severe inflation 下的更强 clean target dominant takeover
- 减少剩余乘法衰减链路对 alpha 的压缩
- 让 actor 真正训练在“更干净的目标”上，而不只是被轻微拉一下

一句话收口：

> `v172` 证明 “inflation-driven takeover” 是对的；下一刀要修的，不再是“会不会接管”，而是“接管后能不能真正压过污染目标”。
