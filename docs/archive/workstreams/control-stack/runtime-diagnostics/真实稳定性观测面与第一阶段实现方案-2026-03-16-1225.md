# 真实稳定性观测面与第一阶段实现方案-2026-03-16-1225

## 一、为什么下一步不是继续修 L2，而是补“真实稳定性观测面”

`v174` 已经把一个关键结构性事实钉死了：

- 晚期真实 eval 已经显著崩落
- 但 imagined 内部仍能给出一组“看起来还算稳定”的指标
  - `policy KL to eval anchor` 很低
  - `imagined corridor persistence` 很高
  - `clean target blend` 也并非为零

这意味着当前系统的核心缺口，不再只是：

- actor 没刹住
- critic 漂得太厉害
- clean target takeover 不够强

而是：

> 系统正在用一组已经失真的 imagined 内部观测量，去代理真实世界中的长期稳定性。

只要这个观测合同不改，后面继续在 L2 上补刀，最多只是改善某些坏相位，不会根治“imagined 内稳、real 外坏”的晚期错位。

## 二、控制蓝图的新增拆分

在现有 `L0/L1/L2/L3` 分层之上，再补一个正交拆分：

- `I 面`: imagined internal stability
- `R 面`: real rollout stability

当前系统已经有不少 `I 面` 观测量，但 `R 面` 观测量几乎缺失。

### 当前已有的 `I 面` 观测量

- `behavior_policy_kl_to_eval_anchor_*`
- `behavior_corridor_persistence_rate`
- `behavior_action_switch / oscillation`
- `behavior_f_policy velocity / acceleration / curvature`
- `inflation_gate`
- `clean_target_blend`
- `open_loop_audit`

这些量很有价值，但它们都发生在：

- imagined branch
- actor-use policy space
- 当前内部 semantic ruler 的参考系里

它们可以告诉我们：

- actor 在 imagined 里怎么看自己
- critic 在 imagined 里怎么看 actor

但它们不能直接告诉我们：

- 真实 rollout 里这条 corridor 还在不在
- 当前 imagined 稳定性和真实稳定性是否还一致

## 三、新的受控量：从“imagined 稳定”升级为“real-imag 一致稳定”

下一阶段不应该把 `imagined corridor persistence` 当作最终被控量。

更合适的被控量应拆成三项。

### 1. 真实 corridor hold

定义：

- 在真实 rollout 中，策略是否能持续停留在一段高回报、低振荡、低漂移的行为 corridor 里

这是最终行为层应该追求的目标量。

### 2. real vs imag corridor mismatch

定义：

- imagined 内部判断“这条轨迹是稳定 corridor”的结论
- 与真实 rollout 验证“这条轨迹确实可持续”的结论
- 之间的差

这是当前最关键的新误差量。

### 3. anchor-certified stability

定义：

- 最近一次被真实 eval 认证过的高分行为
- 在随后的训练过程中，当前策略相对它的偏移，是否仍保持在“真实安全”的范围内

这不是简单的 `KL to eval anchor`，而是：

- `KL` 只是其中一维
- 还需要看真实行为性质是否一起保持

## 四、新的观测面应该长什么样

### A. real corridor 观测量

这些量应该直接来自真实 rollout，而不是 imagined batch。

#### 1. real action entropy

- 作用：
  - 看真实策略是否开始模式硬化
  - 避免 imagined 熵健康、真实熵塌缩却看不见

#### 2. real action switch / oscillation

- 作用：
  - 真实环境里动作是否开始左右摇摆
  - 或者进入僵硬的一边倒策略

#### 3. real corridor occupancy / persistence / entry / exit

关键点：

- corridor 不能再只用 imagined 高 value corridor 定义
- 需要有一个 `real-certified corridor` 定义

第一阶段的务实定义可以是：

- 以最近一次高分 eval 轨迹为 anchor
- 用行为统计而不是 critic value 来定义 corridor

例如由以下条件构成：

- episode return 高于某阈值
- action entropy 处于合理区间
- switch / oscillation 处于合理区间
- pole 角速度 / 小车位置等原始行为量处于稳定区间

#### 4. real policy drift to certified anchor

这不是 imagined `policy KL to eval anchor` 的简单复制。

应区分：

- 在真实 rollout 采样到的状态上
- 当前 actor 相对 certified-anchor actor 的策略偏移

这才是 `policy-to-real-anchor drift`。

### B. real-imag mismatch 观测量

这是下一阶段最关键的新层。

#### 1. corridor occupancy mismatch

- imagined 认为在 corridor 的比例
- 与真实 rollout 实际处在 corridor 的比例
- 之间的差

#### 2. corridor persistence mismatch

- imagined corridor persistence
- 与 real corridor persistence
- 之间的差

#### 3. anchor drift mismatch

- imagined `KL to eval anchor`
- 与 real `KL to certified anchor`
- 是否同步

#### 4. stability-sign mismatch

- imagined 里判断“系统仍稳”的观测组合
- 真实 rollout 中“系统已不稳”的观测组合
- 同时出现的频率

这可以直接作为“观测合同失真”的报警量。

## 五、这套观测面如何嵌入当前系统

### 职责边界

- `L0 world model`：
  - 不承担真实稳定性认证
  - 只负责预测真值

- `L1 bridge/router`：
  - 需要接受 mismatch 诊断结果
  - 但第一阶段不直接背修复责任

- `L2 critic/clean-target`：
  - 继续维护 semantic ruler
  - 但不再被默认视为稳定性最终裁判

- `L3 actor/control`：
  - 最终应该受 `real hold` 和 `real-imag mismatch` 的约束
  - 但第一阶段先观测，不立刻闭环接管

### Iron Wall 的位置

Iron Wall 仍然不动。

新增的真实稳定性观测面不应通过 RL 梯度回流到 L0。

它应该是：

- 一个外部诊断与控制输入面
- 作用于 L3 / 局部 L1
- 不破坏 predictive core 的 truth-protection 原则

## 六、第一阶段最小实现

第一阶段不应该直接做强控制。

目标只有一个：

> 把“imagined 稳定”和“real 稳定”正式拆账，并验证两者的错位是当前晚期主病灶。

### 第一阶段实现范围

#### 1. 在 eval / real rollout 侧新增 real behavior telemetry

最小集合：

- `real_behavior_action_entropy_mean`
- `real_behavior_action_switch_rate`
- `real_behavior_action_oscillation_rate`
- `real_corridor_occupancy_fraction`
- `real_corridor_persistence_rate`
- `real_policy_kl_to_certified_anchor_mean`

#### 2. 增加 certified real anchor

定义建议：

- 不是每次 eval 都替换
- 而是只有当 eval 明确进入高质量段时，才更新 certified anchor

第一阶段可采用：

- `eval mean >= highwater threshold`
- 或者“最近 N 次 eval 中最优轨迹”

#### 3. 增加 real-imag mismatch 指标

最小集合：

- `real_imag_corridor_occupancy_gap`
- `real_imag_corridor_persistence_gap`
- `real_imag_policy_anchor_drift_gap`
- `real_imag_stability_disagreement`

#### 4. 保持主训练合同不变

第一阶段不要：

- 改 actor loss
- 改 critic loss
- 改 controller stage
- 改 clean-target takeover law

这样因果最干净。

## 七、第一阶段的验收标准

### 验收标准 1

当类似 `v174 @1500 -> @2250` 的晚期崩塌再次出现时，必须能观测到：

- imagined corridor persistence 仍高
- real corridor persistence 已明显下降
- 两者 mismatch 显著升高

如果这一点看不到，说明当前判断还不够扎实。

### 验收标准 2

当系统进入早期 pre-inflation behavior drift 时，必须能区分：

- 只是 imagined 内部动作统计先坏
- 还是 real rollout 也同步先坏

这将决定下一刀落在：

- 纯 actor 行为层
- 还是 actor-use geometry / bridge consistency

### 验收标准 3

需要出现一个明确的分叉结论：

#### 如果 mismatch 先升高

说明主病灶是：

- imagined 观测合同失真
- 下一刀应优先修 `real-certified control objective`

#### 如果 real 与 imag 同步一起坏

说明主病灶仍更偏向：

- actor / bridge 本体行为几何问题
- 下一刀可以更直接落在 L3 或 L1

## 八、第二阶段可能的控制方向

只有在第一阶段观测把 mismatch 钉死之后，第二阶段才考虑控制接入。

### 候选方向 A：real-certified actor target gating

- 当 real-imag mismatch 过大时
- actor 主目标不再只听 imagined 内部稳定信号
- 而要受 certified real stability gate 约束

### 候选方向 B：bridge-side real hold consistency

- 不是继续加 L2 semantic regularizer
- 而是在 L1 上约束：
  - “被 imagined 认为稳定的轨迹”
  - 在 real-certified anchor 邻域里也必须保持一致

### 候选方向 C：late-stage mismatch brake

- 这不是 controller rescue
- 而是当 mismatch 高于阈值时
- 降低 actor 对 imagined corridor persistence 的信任权重

## 九、一句话收口

下一刀最干净的主线，不是继续问“怎么让 imagined 内部更稳”，而是先补一层：

> 系统如何知道 imagined 内部的“稳”，是否仍然等价于真实世界里的“稳”。

这就是“真实稳定性观测面”的职责。
