## 内部指标诊断

### 1. 这次修复确实打中了尾段大崩塌

到训练末端 `step=2500`：

- `actor/online_adv_mean = -18.47`
- `actor/adv_mean = -18.44`
- `actor/corridor_semantic_inflation_gate_mean = 0.924`
- `actor/corridor_semantic_inflation_active_fraction = 1.0`
- `imag/value_target_gap_abs_mean = 18.51`
- `imag/open_loop_audit_teacher_value_abs_to_short_return_mean = 42.47`
- `imag/open_loop_audit_imag_value_abs_to_short_return_mean = 41.37`

这说明后段 value semantics 的膨胀依然很重，critic family 的绝对语义并没有被治愈。

但即便如此，最终 eval 还能维持在 `249.4`，而不是像 `v169` 那样掉到 `20.4`。这说明：

- actor 不再像以前那样被完全绑死在污染 target 上
- clean target replacement 已经在 late-stage 起到了“止跌”和“托底”作用

### 2. 这次没有彻底治愈，剩余病灶是“接管覆盖率不足”

虽然到末端：

- `inflation_gate` 已经很高
- `negative advantage` 已经很深
- `clean target available fraction` 也有 `0.34`

但真正的 clean target 接管量仍很小：

- `actor/corridor_semantic_clean_target_blend_mean = 0.0169`
- `actor/corridor_semantic_clean_target_blend_active_fraction = 0.025`

这说明当前系统不是“检测不到病情”，而是：

- 能检测到通胀
- 能检测到负优势
- 也能拿到一部分 clean target
- 但三者在样本级的交集仍太小

因此 clean target replacement 目前更像一个“稀疏托底器”，还不是一个“高覆盖 corridor 接管器”。

这说明在最需要它接管的早期回撤点上，clean target 的各个门已经分别有信号，但样本交集没有对齐，导致替换没有真正落进 actor 主目标。

## 当前判断

### 已确认的部分

1. `AIA-ACSC-v2` 的方向是正确的。
2. 这刀已经显著修复了 `v169` 的“晚期大失稳 + 最终自由落体”。
3. 当前主病灶不再是“actor 完全听不见 clean signal”，而是“clean signal 覆盖率太稀疏”。

### 仍然存在的问题

1. critic / value semantics 的绝对膨胀依旧严重。
2. actor-side clean replacement 的实际接管比例仍偏小。
3. high-value corridor 内，检测、可用 clean target、最终替换三者的样本级重叠仍不足。

## 结论

本次真实 run 给出的最核心结论是：

> `AIA-ACSC-v2` 已经把系统从“late-stage 完全失守”修到了“尾段可保持在较高分数区间”，但它还没有把 clean target replacement 变成高覆盖的主稳定器。

更直白地说：

- 这刀是对的
- 它已经明显有效
- 但现在还不够“厚”
- 下一步真正该修的不是换方向，而是把 clean target 接管从“偶发命中”推进到“corridor 内稳定命中”
