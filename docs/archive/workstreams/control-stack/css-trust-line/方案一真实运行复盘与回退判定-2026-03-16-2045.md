- 方案一确实修掉了“低分假 corridor 完全麻木”的最坏病相。

## 没修好的是什么
- 方案一没有建立稳定的高回报终态。
- 系统后半程持续在中高分和中低分之间摆动，最终停在 `113.2`，没有形成 solved hold。
- 更关键的是:
  - 行为层可以反弹
  - critic 绝对语义仍持续膨胀
  - corridor 仍然会认证一个任务值不高的稳定盆地

## 更深层的失败原因
- 方案一给的是“少信自己”的负反馈刹车，不是“该信什么、该往哪里收敛”的正向主合同。
- 它能减少坏方向推进，但不能单独决定正确的终态吸引域。
- 因此系统表现为:
  - 会自救
  - 会反弹
  - 但不会稳定落回真高值 corridor

## 关键新发现
- 当 `eval` 短时回升时，`task_degradation` 下降，`trust` 会回升。
- 但这时 critic 语义并没有被真正洗净。
- 在 `2000` 左右:
  - `eval = 290.2`
  - `critic_gap_abs = 14.14`
  - `teacher_gap / imag_gap = 30.56 / 28.04`
- 在 `2500`:
  - `critic_gap_abs = 39.06`
  - `teacher_gap / imag_gap = 50.39 / 54.03`
- 说明:
  - reward-health 接入 trust 修掉了“低分时无反应”
  - 但会让 trust 在行为短时恢复后过早恢复
  - bootstrap 纠偏器因此会在 critic 语义尚未洗净时开始松手

一句话:

> 把 reward signal 接进 trust 是对的，但不能让它主导 trust 的恢复节奏。
