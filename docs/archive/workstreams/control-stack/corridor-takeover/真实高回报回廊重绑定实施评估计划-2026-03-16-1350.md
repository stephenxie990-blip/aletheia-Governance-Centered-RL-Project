# 真实高回报回廊重绑定实施评估计划 - 2026-03-16 13:50

## 一、这轮正式验证要回答什么

本轮不是继续猜“又一个 patch 会不会碰巧提分”，而是回答三个更硬的问题：

1. 第一阶段实现是否真的接入了 actor 主推进器，而不是只停留在审计层。
2. `task corridor` 是否能在 reward collapse 之前，给出“内部高价值 corridor 与真实高回报语义脱钩”的可观测信号。
3. 这条 replay-grounded 的新观测面，是否至少能缩小 `v175` 那种“corridor 仍绿、reward 已崩”的系统盲区。

## 二、本轮的控制目标

### 1. 机制目标

- `task_corridor_analytic_scale` 必须真实乘进 actor `analytic_scale_mask`。
- `task_corridor` 相关指标必须在 imagined batch 中形成非零、可解释的状态分布。
- 当 replay 高/低回报原型分离度不足时，actor 不应被全局压制。

### 2. 诊断目标

- 对于高价值 imagined corridor 中的“低任务语义”状态，系统要能给出非零 `high_value_but_low_task_fraction`。
- 对于“几何仍稳但任务语义已偏”的窗口，系统要能通过 `task_geom_corridor_disagreement` 给出可追踪信号。
- 上述信号要能和 `weighted_actor_target_mean`、`critic/value_target_gap_abs_mean` 联动解释，而不是孤立存在。

### 3. 结果目标

- 真实 eval 不要求第一刀就直接稳定 solved。
- 但必须至少改善这一点：
  - 不再对 late-stage 真实塌陷完全无感；
  - collapse 前后的 actor 主推进器应出现与 `task corridor` 一致的削弱。

## 三、正式 run 协议

- 运行对象：CartPole pure-imag。
- 运行长度：`2500 update steps`。
- eval 协议：每 `250` step 做 `5` episode eval。
- 基线比较对象：`v175`。
- 本轮正式 artifact：
  - `outputs/exp_seed42_v177_h15_task_corridor_rebind_fixed_2500_20260316_01`

## 四、正式验收指标

### A. 机制级

- `actor/task_corridor_analytic_scale_mean`
- `analytic_weight_scale_task_corridor`
- `analytic_scale_mask_mean`
- `analytic_weight_scale_task_corridor_active`

判据：

- `analytic_weight_scale_task_corridor` 应与 `task_corridor_analytic_scale_mean` 对齐；
- active fraction 非零时，`analytic_scale_mask_mean` 也必须同步变化。

### B. 行为/诊断级

- `actor/task_corridor_score_mean`
- `actor/task_corridor_gate_mean`
- `actor/task_corridor_confidence_mean`
- `actor/high_value_but_low_task_fraction`
- `actor/task_geom_corridor_disagreement`
- `actor/weighted_actor_target_mean`
- `critic/value_target_gap_abs_mean`

判据：

- 若 late-stage 前出现任务语义脱钩，上述错位指标应先于或伴随 eval 回撤上升；
- `weighted_actor_target_mean` 在错位区间应出现被压制的迹象，而不是继续满推。

### C. 结果级

- eval 曲线本身；
- collapse 是否延后、减轻，或变得更可解释；
- 是否减少 “imagined corridor 指标持续健康但真实得分突然塌掉” 的矛盾窗口。

## 六、失败判据

若出现以下任意情况，本轮视为未达标：

1. `task corridor` 指标有值，但 `analytic_scale_mask_mean` 不跟随；
2. `high_value_but_low_task_fraction / task_geom_corridor_disagreement` 始终近零，无法揭示错位；
3. late-stage eval 明显回撤时，`weighted_actor_target_mean` 仍长期高位，说明 actor 主推进器仍基本无感；
4. 早期学习被全局压坏，说明 gate 过宽或置信度保护不足。
