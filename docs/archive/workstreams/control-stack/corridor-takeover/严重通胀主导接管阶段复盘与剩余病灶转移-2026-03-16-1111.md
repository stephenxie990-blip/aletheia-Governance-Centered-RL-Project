# 严重通胀主导接管阶段复盘与剩余病灶转移 - 2026-03-16 11:11

## 一、阶段目标

本阶段的目标不是再增加一层新脚手架，而是在现有 `AIA-ACSC` 主线上，把 severe inflation slice 中的 clean target takeover 从“能检测、能接入、但执行过弱”，推进到“在真正需要时能拿到主导权”。

约束保持不变：

- 不回 controller rescue 主线
- 不回 critic-only 主线
- 不修改 `base_actor`
- 不新增 detector family
- 不改 world model / Iron Wall 主合同

## 二、执行标准

本阶段开刀前，设定的验收标准是：

1. 早期健康区间不应出现提前接管
2. severe inflation slice 中，`clean target blend` 必须显著高于 `v172`
3. 被污染的 `target_raw` 热度必须被真实压低，而不是只在纸面上报警
4. 实现必须通过本地编译和训练环集成测试
5. 真实 pure-imag run 必须用与 `v170-v172` 可比的启动参数

## 三、实现内容

代码落点：

- `aletheia/aletheia_train.py`
- `aletheia/tests/test_training_loop_integration.py`

本轮没有推翻既有 `floor + bonus` 结构，而是在其上增加 severe inflation dominant takeover：

```text
existing_alpha = floor_alpha + bonus_alpha
dominant_alpha = blend_max * inflation_gate * clean_target_confidence * target_gap_need
blend_alpha = max(existing_alpha, dominant_alpha)
target_actor = lerp(target_actor_raw, clean_target, blend_alpha)
```

核心思想：

- `neg_adv` 不再决定 clean target 是否有资格说话
- severe inflation 下，只要 `target_actor_raw` 相对 clean target 的偏差足够大，就允许 clean target 直接提高接管强度
- 仍然不改 `base_actor`，保持因果干净

## 七、病灶判断的更新

本轮最关键的新结论不是“再把接管力度调更大”，而是：

> severe inflation late-stage 的 actor-side clean replacement 已经明显起效，但系统还同时存在一个更早、且不以 inflation 为前导信号的行为层不稳定点。

决定性证据是 `@1000`：

- `eval = 9.6`
- `inflation_gate = 0`
- `critic/value_target_gap_abs_mean = 2.85`
- `teacher_value_abs_to_short_return_mean = 1.40`
- `imag_value_abs_to_short_return_mean = 1.38`

这说明：

- `@1000` 的崩落不是由本轮 dominant takeover 误触发导致
- 也不是 late-stage common-mode inflation 的直接再现
- 当前剩余主问题已经部分前移到 policy / behavior instability

## 八、当前最准确的阶段结论

### 修对了什么

- 修对了 severe inflation 下 clean target takeover 的执行强度
- 修对了 `neg_adv` 充当生死开关的结构缺口
- 修对了 polluted target 热度无法被真实压低的问题

### 没修完什么

- 没修掉 `@750 -> @1000` 的非通胀型崩落
- 没修掉 late-stage critic / base 的绝对膨胀
- 没拿回类似 `v170 @2500 = 249.4` 那样的长期 corridor hold

## 九、下一步建议

下一步不应继续盲目加大 clean target takeover，也不应回退到 controller 或 critic-only 主线。

更合理的下一层诊断方向是：

1. 对 `@750 -> @1000` 做 policy / behavior instability 审计
2. 检查当前审计体系是否漏掉了更早的 policy-space warning signal
3. 区分：
   - actor 自身目标造成的行为振荡
   - critic / replay / bridge 几何变化对行为的前置污染

阶段性判断：

> `v173` 已经把问题从“晚期 severe inflation 接管不够强”进一步收紧到“还存在一个更早、非 inflation-led 的行为层失稳点”。这比上一轮更接近根因，而不是更发散。
