# 严重通胀主导接管实现与真实验证-2026-03-16-1107

## 一、本轮目标

本轮要验证的不是“再堆一层 detector / guard”，而是：

> 在 severe inflation slice 中，把 clean target 从弱 blended correction 提升为按 `raw target vs clean target` 错位幅度自动增强的主导替代合同。

约束保持不变：

- 只动 actor-side
- 不回 controller rescue 主线
- 不回 critic-only 主线
- 不动 `base_actor`
- 不新增 detector family

## 二、实现内容

### 1. actor-side takeover law 升级

在 `aletheia/aletheia_train.py` 中，保留原有：

- `floor + bonus`

同时新增：

```text
dominant_alpha =
    clean_target_blend_max
    * inflation_gate
    * clean_target_confidence
    * target_gap_need
```

其中：

- `target_gap_need = relu(target_actor_raw - clean_target) / (abs(target_actor_raw) + abs(clean_target) + 1)`

最终：

```text
blend_alpha = max(floor + bonus, dominant_alpha)
target_actor = lerp(target_actor_raw, clean_target, blend_alpha)
```

这条 dominant path 不再受 corridor top-quantile 限死，直接用 actor 真正训练的 `target_actor_raw` 和 `clean_target` 错位幅度驱动接管强度。

### 2. 新增审计指标

新增了 severe-inflation slice 的核心对账量：

- `actor/corridor_semantic_clean_target_dominant_gap_mean`
- `actor/corridor_semantic_clean_target_dominant_alpha_mean`
- `actor/corridor_semantic_clean_target_blend_inflation_weighted_mean`
- `actor/corridor_semantic_target_raw_inflation_weighted_mean`
- `actor/corridor_semantic_target_inflation_weighted_mean`
- `actor/corridor_semantic_target_gap_inflation_weighted_mean`

### 3. 测试调整

- 保留原 replay clean target 路径测试
- 重写 floor 测试口径：
  - 不再假设 `no-floor => blend=0`
  - 改为验证 `floor_mean` 是否独立存在
- 新增 dominant takeover 定向测试：
  - `raw target vs clean target` 错位越大
  - `dominant_alpha` 必须越高
  - `target_actor` 必须被更明显拉向 `clean_target`

## 七、结论

### 1. 修对了什么

本轮已经真实修到：

- dominant takeover 不再只是纸面设计
- 在 severe inflation slice 中，它确实能显著抬高 clean target 接管强度
- 并把 actor 主目标的热度压下来

### 2. 没修完什么

它仍没有把系统修到 `v170 @2500 = 249.4` 那样的长期保持力。

当前形态更像：

- 前段显著增强
- 中段出现一次非通胀型行为崩落
- 后段能恢复，但保持力仍不够

### 3. 当前最准确的判断

当前剩余问题不宜再简单表述为：

> clean target takeover 不够强

因为 `v173` 已经证明：

- 接管确实更强了
- polluted target 也确实被压住了一部分

更准确的表述应更新为：

> severe inflation late-stage 的 actor-side clean replacement 已经打中病灶并起效，但系统还同时存在一个更早、且不以 inflation 为前导信号的策略行为振荡问题。

## 八、下一步方向判断

基于 `v173`，下一步不应回退到：

- controller rescue 主线
- critic-only 主线
- 继续只堆 actor-side clean-target strength

因为：

- late-stage 接管已明显增强
- 但 `@1000` 的崩落发生在 `inflation_gate = 0`、semantic audit 仍健康的时候

这说明新的残余主问题已经部分前移到：

> policy / behavior 层面的中段不稳定，而不仅仅是 late-stage value inflation。

因此，下一轮应优先围绕：

- `@750 -> @1000` 的行为相位切换
- policy-space / action-level 稳定性
- 以及这段崩落是否先于 value semantics，还是当前 audit 仍缺失了更早的行为型预警量

做更细的结构诊断，而不是继续盲目放大 clean-target takeover。
