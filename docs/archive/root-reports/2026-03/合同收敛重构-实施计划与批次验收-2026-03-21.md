## 固定验收程序

每个 Batch 完成后都执行以下四步：

1. 结构验收

2. 回归验收
   - 跑该 Batch 对应 focused tests
3. 工程验收
   - `./.venv/bin/python -m compileall aletheia`
4. 节点记录
   - 更新 [task_plan.md](/Users/zhangsan/Desktop/缸中之脑v5.6/task_plan.md)
