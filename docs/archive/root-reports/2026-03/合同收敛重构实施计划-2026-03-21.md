# 合同收敛重构实施计划

日期：2026-03-21
项目：`/Users/zhangsan/Desktop/缸中之脑v5.6`
范围：`aletheia/` 合同收敛重构，按 `Batch A -> Batch J` 顺序执行直至完成

## 1. 目标

本轮不再继续扩散实验刀口，而是把当前已经散落在 `aletheia_train.py` 顶部 helper、post-transition hold/persistence、controller 最小补偿、config/metrics/resume 表面上的“合同式语义”统一收敛为三类一等对象和两类附属载体：

- 非合同载体：
  - `EvidenceBundle`
  - `MinimalCompensationState`
- 一等合同对象：
  - `CertificationState`
  - `AuthorityDecision`
  - `ConsumerDirective`

本轮最终目标不是重新修模型行为，而是把现有主链从“多 helper 串接 + 多指标冒充接口”重构为“显式对象边界 + 可审计状态 + 可收敛配置域”。

## 2. 固定原则

1. 不重新扩写 controller。
2. 不把当前不过线主因重新归咎到 `WM core`。
3. 先收敛接口与边界，再谈后续 Phase 4 主线实验。
4. 每个 Batch 都必须经过同一套验收程序，未通过不得进入下一批。
5. 当前工程不是 git repo，因此回滚依赖：
   - 节点文档
   - 文件级变更清单
   - 保守补丁
   - 编译与定向测试门禁

## 3. 使用的 Skills

- `pi-planning-with-files`
  - 用途：把任务分解、发现、进度、错误和验收沉淀到项目内文档。
- `agentic-engineering`
  - 用途：先定义完成条件，再拆批次、拆风险、拆验证。
- `verification-loop`
  - 用途：每个批次完成后按固定核验口径执行 compile/test/diff-review 风格检查。

## 6. 每个 Batch 的固定验收程序

每个 Batch 完成后必须按以下顺序核验：

1. `compileall`
   - `./.venv/bin/python -m compileall aletheia`
2. 合同层定向单测
   - 针对本批新增模块/对象的 focused tests
3. 训练循环集成回归
   - `aletheia.tests.test_training_loop_integration` 中与本批相关的 focused regression pack
4. resume/checkpoint 回归
   - 至少执行 `test_run_train_uses_agent_collector_and_writes_resume_artifacts`
   - 若状态/配置面有改动，则追加相关 resume tests
5. 人工审查
   - 是否引入新的一等对象泄漏
   - 是否仍有 train 顶层 helper 语义重复
   - 是否出现“新对象只是旧 helper 包一层皮”

## 7. Batch 级验收标准

### 代码标准

- 新对象必须显式命名并承担稳定边界
- 不允许新模块反向依赖 controller 脚手架
- 不允许把 telemetry 字段直接当领域对象

### 行为标准

- 结构重构不允许改变当前主训练语义
- 若必须保留兼容别名，必须明确生命周期

### 测试标准

- 新对象必须有最小单测
- 旧训练主线 focused regression 必须保持通过
- resume/state 改动必须补 roundtrip 测试

### 审查标准

- 每批结束后记录：
  - 修改文件
  - 删除文件
  - 新增测试
  - 风险点
  - 回滚点

## 8. 回滚准备

当前无 git，因此采用三层回滚准备：

1. 文档回滚
   - 每批记录起止点、目标、受影响文件、通过的验证
2. 结构回滚
   - 每批尽量保持“抽离 + 调用点替换”的局部补丁
3. 逻辑回滚
   - 若某批验证失败，只回退当前批新增模块与接线，不动前批已验收对象

## 9. 完成定义

满足以下条件才算本轮完成：

1. `Batch A -> Batch J` 全部完成。
2. 合同收敛后的对象边界在代码中成立。
3. focused compile/test/resume 验证全部通过。
4. planning files 已记录最终状态。
5. 遗留 helper 与 legacy scaffold 已完成删除或降级。
