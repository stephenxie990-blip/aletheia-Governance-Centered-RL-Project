## 3. `v232` 到底证明了什么，没证明什么

### 3.1 已经证明的部分

`v232` 已经证明：

- 当前 Phase 4 的执行底座是稳定的
- `Phase 4.15` 没有破坏 early-safe 路径
- `Phase 4.15` 没有复现“更强 retention 导致更坏终局”的明显错误
- 在真实 run 里，这条线可以把晚窗行为稳定拉到最强结果

这意味着：

> SAI 路线没有失败。
> 当前路线已经从“是否方向错了”的阶段，进入“如何在正确层上继续收敛”的阶段。

### 3.2 还没有完全证明的部分

`v232` 还没有完全证明：

- `release` 本身就是 `2250 = 500.0` 的直接主因
- `Phase 4.15` 已经把 `1500/1750/2000` 的中后段稳定性彻底做完

原因很明确：

- `2250` 时：
  - `late_gate = 0.8203`
  - `release_window_activation = 0.0`
- `2500` 时才出现：
  - `late_gate = 1.0`
  - `release_window_activation = 1.0`

所以现在最准确的结论不是：

> `release` 已经被完整证明是最终根因修复。

而是：

> `Phase 4.15` 已经证明自己至少没有再把系统推向 `v231` 的错误 retention 模式，
> 并且在真实 run 中拿到了当前最强的晚窗表现。
