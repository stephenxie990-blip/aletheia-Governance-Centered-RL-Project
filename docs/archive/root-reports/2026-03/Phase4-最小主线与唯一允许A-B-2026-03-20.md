## 5. 后续只允许跑的 2-3 个 A/B

## A/B-1：`v242` 精确基线 vs `Phase 4.22B historical-authority dominance`

这是唯一无条件必须跑的 A/B。

固定不变项：

- 与 `v242` 完全相同的 `seed / steps / eval_interval / eval_episodes`
- 完全相同的 resolved config
- 完全相同的 helper 输入输出接口
- 不允许顺手改窗口、阈值、hold path、entry、actor、controller

唯一变量：

- `post_transition_certified_capture_source` 的组合规则，必须保证：
  - 在 `window fully active`
  - 且 `support > 0`
  - 且 `historical authority > current authority`
  - 时，`capture_source` 至少在一个关键点上能严格大于 `current authority`

通过标准：

- 结构上：
  - 至少一个 `2000 / 2250 / 2500`，满足 `capture_source > current_authority`
  - 至少一个 `2000 / 2250 / 2500`，满足 `persistence_gate_floored > source_hold_persistence_gate_mean`
- 行为上：
  - `2250 > 25.0`
  - `2500 > 22.5`
  - 且不允许 `1250 / 1500` 回归到差于 `v242`

如果连结构条件都过不了，主线不许外扩。

## A/B-2：`A/B-1` 胜者 vs 同口径精确 rerun

这是第二个必须跑的 A/B，但只有在 `A/B-1` 结构通过后才允许启动。

目的不是继续找新刀，而是回答一个更硬的问题：

> `A/B-1` 的结构改进，到底是有效改进，还是单次噪声。

固定要求：

- 完全同口径 `15 ep`
- 不允许带入第二个代码变量
- 只做“胜者代码 vs 基线代码”的精确 rerun 对照

通过标准：

- 两次运行都出现 `capture_source > current_authority`
- 两次运行都出现 `persistence_gate_floored > raw gate`
- 行为方向一致，不允许一次改善、一次回平

如果 `A/B-2` 不稳定，则不许进入下一层。

## A/B-3：只在 `capture source` 已打穿但行为仍平时，才允许做 `floor-to-gate coupling`

这是条件性第三个 A/B，不是默认开放项。

启动前提必须同时满足：

- `A/B-1` 结构通过
- `A/B-2` 结构复现
- 但 `2250 / 2500` 行为仍基本贴着 `v242`

那时才允许把下一刀收缩到：

> floor downstream coupling 是否太弱，导致已经改好的 capture source 没有真正转成 actor/critic 可消费的 persistence 托举。

这时的 A/B 也必须保持：

- 只动 `hold_state_floored / persistence_gate_floored` 的下游耦合
- 不得回头再改 capture source 以外的旧层

## 6. 明确停止条件

出现下面任一情况，当前主线必须停止扩写：

1. `A/B-1` 仍然出现 `capture_source == current_authority` 的同型结果。
2. `A/B-1` 虽然结构 nominally 有变化，但 `1250 / 1500` 明显回归。
3. `A/B-2` 不能复现 `A/B-1` 的结构优势。

停止之后只允许两种动作：

- 回到同一 helper 内，继续缩 `capture_source` 的组合语义
- 或正式裁决“本阶段主问题已不在 capture source 本体”

不允许的动作：

- 回 corridor
- 回 entry/trigger/threshold
- 回 actor/controller
- 把失败重新归到 `WM core`

---

## 7. 正式 promotion 条件

只有在下面条件同时成立时，才允许从 `capture source` 层升到下一层：

- 至少两次同口径 run 证明 `capture_source > current_authority`
- 至少两次同口径 run 证明 `persistence_gate_floored > raw gate`
- `2250 / 2500` 行为不再完全贴着 `v240 / v241 / v242`

在这之前，任何“换层找原因”都属于扩大搜索面。

## 8. 最终固定句式

当前最小主线的正式表述应固定为：

> `v242` 完整跑完后，`Phase 4.22` 仍未证明 “历史 authority 优先” 已在真实数值上生效；当前唯一允许继续推进的主线，是在同一 helper 内把 `post-transition certified capture source` 做成一次真正高于 `current authority` 的受支撑历史接管，并只用 2-3 个同口径 A/B 来验证这一件事。
